# 全凸包面法向审计：闭运算实现反例

## 本轮结论

同一组保存阶段坐标在16方向检查中通过，不能推出它们满足完整凸包包含。
新v3使用源顶点集的全部精确凸包面法向，首批8个已启动旧输入均在第一阶段
`closed_in_input_hull`出现违反，批次停止；不重启，不补抽，不增加经验pad放行。
这反驳的是将精确欧氏闭运算引理直接套到保存GEOS闭运算顶点的实现前提。
不是对精确集合引理的反驳，也不能据此推断旧物理运动或原服务预算已经违反。
默认服务门控保持不可认证／贪心回退，完整Step1研究目标未完成。

## 检查与复判的具体含义

`analysis/exact_convex_hull.py`将全部二进制坐标变为共同二次幂分母上的整数，
以整数叉积构造凸包，去除重复及共线内部顶点，保留低于float方向判断分辨率的凸起。
对CCW凸包边a→b，取精确外法向 `(b_y−a_y, a_x−b_x)`，约去整数公因子。
闭运算输出在全部这些支撑半平面中，当且仅当其所有顶点在该固定源凸包中。
若检查通过，连接输出顶点的弦由凸性也在其中；这仍只是固定输入的几何判定。

独立复判不调用这个凸包构造器：从原顶点核验凸包证书，要求相邻转向严格CCW，
全部源点在每条边的左闭半平面内，再从有理边向量独立导出法向。
这些条件确认所给凸多边形既包含全部源点，又由源点组成，因此就是源点凸包。
然后用直接Fraction点积核对每个支撑值、违反集合及保存有理差。

v3若进入正偏置阶段，也会检查源凸包全部面法向；但偏置后的这些有限半平面只是
圆盘Minkowski扩张的必要约束，不能据此判定所有圆角区域。v3实际在第一阶段已停止，后续阶段未检查。
重采样阶段原计划使用偏置凸包全部面法向加坐标轴及已有条件插值外包，本批同样没有进入该阶段。
不能将“全部源凸包面”写成“所有方向的欧氏扩张证明”，也不能将未执行阶段预记通过。

## 一个精确反例

旧真实快照group0中，保存闭运算顶点q：

    q = (11.994970277604262, 16.993551578820014)。

源凸包面外法向

    n = (918379445212, 3666376263701)。

源顶点最大支撑为20637939029806693125741940459/281474976710656，
q的支撑为20637939029806695118894461841/281474976710656，
差为996576260691/140737488355328，严格为正。
该法向未单位化；不能把这个约0.0070811的原始点积差当成空间距离。
除以‖n‖后的法向超出量约1.873481615855563e−15m，其平方精确为

    993164243372855991797481 /
    282958147664820893143054906310295395983653526285844480。

其余七个输入各自最强法向超出量约1.4934879273752877e−15m。
比较本身使用精确有理值／平方，不以float平方根或该显示近似值放行。
本例q也作为相同坐标的占据外环顶点保留下来；它不是仅存在于未使用中间数组的点。
但没有由此宣称最终原参考超出某个已有带外包余量的支持域，更没有宣称旧安全／服务阈值已违反。

## 局部偏置／相交重建与归因边界

按固定GEOS3.14.1的[偏置与相交源码](https://raw.githubusercontent.com/libgeos/geos/3.14.1/src/operation/buffer/OffsetSegmentGenerator.cpp)，
从保存正buffer的相邻第103、104条线段计算负偏置线段端点。
两条保存二进制端点线段的精确有理交点z存在，参数分别为

    t = 3150488597203755401439805 / 6147425686943647418515482，
    s = 512594194990032595781357 / 2049141895647882472838494。

两参数都在[0,1]，z在原凸包全部面内，并且恰在上述见证面上。
将z逐坐标按最近二进制64位舍入后，结果与保存q逐位相同。
坐标舍入误差的n加权和精确等于上述正支撑差；这一组具体数值有完整算术解释。
它与此前1/2^49的重采样反例、0.734504mm的通用圆角弦反例分别记账，不能混为同一个机制。

这是匹配一手源码表达式的局部构造重建，不是内部插桩证明唯一执行路径，
也不意味着所有GEOS交点都是精确有理交点的正确舍入。
此外原环在偏置前还经过[OffsetCurveBuilder中的简化](https://raw.githubusercontent.com/libgeos/geos/3.14.1/src/operation/buffer/OffsetCurveBuilder.cpp)，
不能忽略简化、顶点合并、偏置、交点求解及布尔结点处理而将本例误差作为普适界。
