# 声明质量集合上的联合预算检验

本研究基础件实现于`src/udc/multigroup/mass_ambiguity.py`。它不是观测到原参考的质量外包，也没有接入运行控制器。
质量集合上的最坏线性函数优化是已有鲁棒优化思想，不作为本项目首创贡献。
文献定位及后续比较见[方法与基线审查](../reports/step1_foundation_20261029/LITERATURE_AND_BASELINES.zh.md)。

## 条件命题

对同一原世界参考，设一个覆盖全参考的互不相交可测划分，单元质量为`m_i`。
其真实有符号服务差的逐点指标由`s_i ∈ {-1,0,1}`上界：+1丢失、−1新增、0中性。
这要求划分／分类覆盖整个允许原世界，并按冻结协议包含服务半径及跟踪条件。
只知道支持域几何框并不能构造这些质量约束。

假设已从观测证明，每个允许原世界的质量向量都属于非空集合

    A = {m : 0 ≤ l_i ≤ m_i ≤ u_i,
              T_low ≤ sum(m_i) ≤ T_high},
    max(sum(l_i), T_low) > 0.

运行协议预算仍是配置0.002，其binary64精确值为`1152921504606847/576460752303423488`，
hex为`0x1.0624dd2f1a9fcp-9`。首轮纯代数夹具用0、精确十进制`1/500`及1，
另以原运行binary64预算复核同一批集合；二者的表示明确分开，不替换运行阈值。
由于同一向量的分子与分母共享总质量，对精确单元符号有等价关系

    sup_{m∈A} [sum(s_i*m_i)/sum(m_i)] ≤ δ
       iff max_{m∈A} sum((s_i−δ)*m_i) ≤ 0.

若`s_i`只是逐点上界，右式仍是服务损失预算的充分条件，不能解释成真实最坏损失的精确值。
若集合没有原世界外包证明，以上结论仅属于声明集合。
若右式为正，其最大化向量是放松质量集合中的反例，不自动是可实现的人员世界。

## 求解与推导

从所有下界开始，令`c_i=s_i−δ`。先按`c_i`降序填充至可行总质量下界；
再只向正系数单元填充，直至上界或总质量上界耗尽。全部输入及运算使用`Fraction`，不加比较容差。

固定总质量时，若较低系数单元尚有可转移质量而较高系数单元未满，把两者间的质量转移只会增加目标。
故排序填充在每个固定总质量上最优。达到强制下界后，只有正系数还值得增加总质量；零系数可任选。
这给出本集合上的精确最大值。空集合与缺少正总质量下界均明确拒绝，不用空集真命题放行。
实现返回`original_reference_enclosed=False`及`runtime_service_certificate=False`。

共同总质量能提供额外约束。例如丢失／新增／中性分别在`[0,1] / [0,100] / [0,98]`，总质量恒为100。
分离极值界为`(1−0)/100=0.01`，不能证明0.002；共同总质量迫使新增质量至少抵消丢失质量，精确最坏净差为0。
联合预算残差最大值为`−1/5`，由`(1,1,98)`取得。这是人为代数例，不是旧部署或新独立人群结果。
