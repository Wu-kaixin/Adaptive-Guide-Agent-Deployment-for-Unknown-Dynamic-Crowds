## 条件性算术外包的推导

假设给定二进制64位有限端点a、b，各坐标绝对值≤2^500，基本运算按最近值舍入。
这限制保证下列中间值不溢出；次正规数由η显式处理。
GEOS对t≤0或t≥1直接返回端点；其余情况0<t<1。
弧长定位的误差可以改变线段或t，但不改变“某条给定线段和被截断t”的本节结论。
不声称验证了编译器任意fast-math改写、非最近舍入模式或整个GEOS二进制。

令u=2^−53，η=2^−1075。在包含次正规数的有限最近舍入运算中，采用绝对界

    |RN(z)−z| ≤ u|z|+η。

对每个坐标，令d=b−a为精确有理差，d_hat=RN(b−a)为二进制差。
减法误差e_d=|d_hat−d|由给定端点精确计算。对所有t∈[0,1]：

    e_p = u|d_hat|+η，
    e_a = u(|a|+|d_hat|+e_p)+η，
    |RN(RN(d_hat*t)+a) − (a+d*t)| ≤ e_d+e_p+e_a。

分坐标乘加若融合成一次FMA，其误差也不超过这个较宽的界。
对环上全部线段、每坐标取最大B_j，得到所有插值输出相对某个精确凸组合的坐标误差外包。
任意整数方向n的半平面上界为

    h_upper(n) = max_vertex n·v + |n_x|B_x + |n_y|B_y。

在全部计算中使用有理数，不将η向下舍成0，也不以float平方根判断支撑包含。
连接这些输出点的直线弦由半平面凸性也包含在同一外包内。
这是由运算模型推导出的外包扩张，**不是安全／服务／包含判断的容差放行**；原参考坐标及阈值不改变。
