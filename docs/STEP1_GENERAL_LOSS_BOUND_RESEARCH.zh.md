# 原参考定量损失界：当前推导任务与不能跳过的条件

## 当前实现前提修订

通用圆角buffer内包含前提已被一般多边形反例否定；原族有限扫描未反驳不等于补齐证明。
活动支持域门控因此显式不可认证／贪心回退，须先恢复模型包含依据再研究非零误差有符号质量界。
旧经验数据和独立轨迹复判不改写，见[前提审计与回退](STEP1_BUFFER_ENCLOSURE_AUDIT.zh.md)。

本文件是未完成的研究推导任务，不是已实现或已验证的新证书。
静态原参考仍由未知真实人员经原闭运算、填孔、外偏移及折线重采样产生。
不把真实参考输入控制器，不改成一个更易认证的锚定参考，不把误差集改成统计抽样集。

## 已有组成件

观测充分群身份条件、原参考支持域、可选单调包络，以及`demand_envelope.py`的区域Gaussian结点场对数界。
640对原动作开发结果仍为0认证。点值场界没有给出曲线长度或质量界。

设完整机器人布局为Q，服务半径R，允许终态跟踪误差τ。
保留与贪心的潜在正损失集合包含于

    A = S ∩ (C_greedy^(R+τ) \ C_retained^(R−τ))

其中S为原参考的观测外包支持域。要得到非二值的真实未覆盖损失上界，需建立

    U_retained − U_greedy ≤ M_original(A) / M_original(total)
    M_original(A) ≤ M_lost_upper,
    M_original(total) ≥ M_total_lower > 0.

两项质量界都必须从观测与声明条件得到。支持域面积不是沿原折线的弧长或需求质量。

## 可继续证明的方向

1. 令h为贪心中心到保留中心的单向Hausdorff距离。正损失只能发生在某个贪心服务圆盘的外环带，
   对跟踪界需同时计入两侧τ。这个几何包含不依赖真实曲线，但仍没有限制该曲线在环带内的需求质量。
2. 原mass_cvt需求在每条曲线上乘同一个最大值归一化因子；当tiny下限未激活时，该因子在比例积分中抵消。
   需要用可靠的log域界先检查tiny下限条件，不能把数值下溢当作零质量。
3. 原评价沿结点需求作分段线性积分。即使某个弦点位于A，相关结点也可能在A之外；
   使用点值场界时必须外包相邻结点，不能直接将沿弦的Gaussian场替代原线性插值。
4. 关键缺口是未知原参考与环带相交的弧长上界，以及全参考正质量下界。
   可以研究观测可证的局部图／法向范围／拓扑稳定条件，或完整参考构造的有限复杂度包络。
   必须覆盖闭运算及重采样，不能直接宣称人员误差ε等于原曲线Hausdorff误差。
5. 当前实现是圆角多边形及采样折线。凸折角不满足任意光滑曲线的滚动圆或曲率假设；
   不可直接套用平滑边界的横截性或曲率界而不证明多边形／弦段版本。

上述条件若不能由观测证明，则继续UNCERTIFIED并回退原策略；不通过真值筛选认证。
理想几何推导、float64审计和形式区间证明要继续分开。

后续开发需保留seed2210反例、全部原低资源动作和未认证分母，完成实际服务损失审计后才冻结新输入确认。

## 丢失／新增项的开发诊断与下一种界

640对旧动作的固定真值诊断显示：593对逐群净损失≤0.002，但其中218对的单向丢失质量超过0.002。
160对零扰动为相同布局；非零扰动480对中433对净合格、215对单向丢失合格，见
[原始分解结果](../reports/step1_foundation_20261029/SERVICE_EXCHANGE.zh.md)。这些数不是最坏情形认证率。

可继续推导的充分界为

    B_k = max(0, M_lost_upper,k − M_gained_lower,k) / M_total_lower,k.

各界必须同时覆盖同一组允许真值；分开取极值仍可能过宽，需要进一步研究配对耦合。
找到一个真值下的小净损失不能替代对全部允许真值的界，也不能把最差群指标之差替代每群损失。
当前需求场点值界、支持域面积和单向中心Hausdorff距离均不足以单独推出这些质量界。

下一开发诊断是“同观测、同布局、不同可行静态真值”的不可区分性见证：
保留原人员属性和布局，按观测误差球内的显式扰动搜索两个参考均可定义、群身份／物理条件均有效的世界。
若逐群净损失跨越0.002，说明该输入不能仅按已实现真值的合格情况放行。
见证属于开发／模型分析，不是原随机生成器的新独立样本；没有找到反例也不是通过证明。

该诊断现已完成：20对后验选定动作、640个替代世界全部满足四帧误差与物理／参考条件，
5对有25个跨预算见证。660世界重建通过，完整覆盖积分与有符号交换积分差异至多4.388850394221322e−16。
见[可行世界结果](../reports/step1_foundation_20261029/FEASIBLE_WORLDS.zh.md)。
因此不能将593对单个真实世界的合格解释为593对都应被一般误差证书接纳。
剩余15对未找到见证也未获认证；有限共同平移搜索没有覆盖全部独立人员扰动。
后续界必须明确其可观测附加条件如何排除这类观测不可区分的坏世界，不能放宽0.002或读取真值。

2026-10-29的扩大搜索保持同20对、同观测与布局，纳入误差球交集内的整体及逐群刚性平移：
4096候选中13对有188个跨预算世界，另冻结全部4116世界复判通过，原5对的25候选见证全部保留。
这些20对只有16种原物理真值指纹，且是后验挑选；13/20不是总体比例，没找到见证的7对仍无证书。
下一步须将“支持域包含的实现前提”“未知原参考的有符号质量界”“同观测下的实际不可辨识”分别处理。
补前两项不能自动排除第三项；一般非零误差下的可用证书仍须给出可观测的充分条件，保持原δ和全部拒绝分母。
