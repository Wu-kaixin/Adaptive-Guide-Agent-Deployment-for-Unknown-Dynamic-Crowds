# 观测历史到静态人员位置外包

`multigroup/static_person_enclosure.py`只读取已声明的静态观测帧、稳定人员ID和已知矩形房间，
构造每个人真实中心的有理轴框；构造函数不读取评价真值、生成区域、布局或服务结果。
这是允许人员世界到几何输入的第一层外包，不是原曲线／偏置端点或服务证书。
默认稳定更新门控未改，F4和全部闭环目标未完成。

## 静态输入契约

各帧必须使用`udc.step1.static_global.v1`；人员ID集合、准确身体半径和可观察需求权重保持一致。
允许帧内行顺序改变，按ID对齐；重复frame_id、逆序时间、动态阶段或静态属性变化拒绝。
这项推断依赖人员在各帧之间不移动，不能用于尚未定义的Step2动态误差模型。

设第i个人的未知静态中心为p，房间尺寸为W、H，准确身体半径为r；
第t帧中心观测o_t，误差声明ε_t，均按保存binary64值的精确有理数解释。
允许中心满足||p−o_t||²≤ε_t²，且r≤p_x≤W−r、r≤p_y≤H−r。
本外包保留所有满足这些约束的实数中心，因而也保留其中可表示的二进制中心。
人与人分离、原分群、参考可定义性和可达布局还有其他约束；这里的非空框不证明整个世界可行。

初始框逐坐标相交所有[o_t−ε_t,o_t+ε_t]及身体／墙界。
随后对每一圆盘，计算另一坐标到当前区间的最小精确距离d：
若ε_t²−d²<0则给出矛盾见证，否则当前坐标限于o_t±sqrt(ε_t²−d²)。
平方根以整数isqrt构造向外2^-160格点上界，无浮点容差放行；每次收紧均保留所有允许中心。
最多8轮，预算仅影响松紧，不以迭代停止宣称已求得精确交集。
初始框空、圆盘缺交或传播框空均返回显式矛盾见证及已完成轨迹，不给下游部分人员框冒充全体结果。

## 两圆盘联合约束

v1的独立坐标传播会丢掉同一圆盘两坐标的关联；本批所有历史上的该传播收紧次数均0。
v2加入`multigroup/disk_pair_enclosure.py`，先用每对观测圆盘交集的轴框约束中心。

设两中心a、b，半径r、s，δ=b−a，D²=δ·δ。
D²>(r+s)²时精确不交；D²≤(r−s)²时采用较小圆盘，包含同心、零半径和内部相切。
其余情形的边界交点为a+tδ±perp(δ)sqrt(q)，其中
t=(r²−s²+D²)/(2D²)，q=r²/D²−t²≥0。
每个坐标极值必在这两个交点，或在一个圆的坐标极点且该点位于另一圆内。
坐标极点用有理平方距离直接筛选，交点用sqrt(q)的有理向外上界，得到保守轴框。
外部相切q=0也按精确值处理；不借用GEOS几何谓词。
将这些两两交集框与当前框相交，再做原有限轮传播；不声称两两框已刻画全部允许世界。

每次非平凡收紧保存原框、所用观测ID、平方根被开方数与上界，以及新框。
静态矛盾不是部署成功；有限非空外包不是唯一位置、稳定分群或需求质量的证明。

## 冻结旧世界开发与只读复判

两版本都使用同一后验选择的20个旧动作案例，18种不同观测历史、16种原人员物理指纹。
每例使用旧四帧历史；legacy帧的稳定行索引作ID、序号作顺序，不能冒称重新测得的身份跟踪或释放时间。
这是完整历史的回顾分析，未把尚未收到的未来观测交给在线控制器。
20案例共有2894个人员案例，含重复人员；4116个已保存允许世界不是4116个新独立物理输入。

这是重复人员案例上的外包宽度诊断，不是空间需求质量、服务收益或总体概率；改善较小，不能据此宣称低资源问题解决。

独立冻结复判不调用核心收紧迭代器：从原观测重建初始框，直接核对每步必要包含关系，
用另一种交点判别式4r²D²−(r²−s²+D²)²及平方比较验证根上界，再核对保存最终框。
世界成员、精确观测圆盘及身体／墙检查重复使用同一个有理评价例程，不冒称两套不同成员检查实现。
188个既有跨预算世界全部保留；位置框收紧没有消除已证明的同观测服务不可辨识。
没有重算布局、运行运动、改变原参考／阈值，或新增独立人群输入。
