# 连续服务评分与静态重观测下的布局保留

本模块是独立选择的新实验，不改变单群集成基线或正在执行的v2确认。
人群真值静态、全局观测、通信不受限、无行为交互，机器人姿态/人员半径/需求精确。
新诊断比较同一静态场景的名义观测与重观测；它不使用原确认中“一次观测后冻结”的协议来
声称已验证反复重规划，也不将本实验作为动态人群或闭环稳定性证明。

## 方法与控制器可见输入

核心方法位于`src/udc/multigroup/phase_retention.py`。
输入只有观测人员、观察群体与曲线、共同自由空间、固定每群数量、配置及名义目标。
控制器不接收`StaticTruth`、真实分群、参考曲线或真值服务分数。

每个名义观测先用原观察目录minimax求一次数量，随后固定数量，以隔离布局相位切换。
所有候选仍由原256点Lloyd与8个相位生成。三种贪心选择分别用：
采样弧距缺口、连续弧距缺口、连续欧氏缺口；代价破同分仍用原观察弧距成本。
因此“连续”指对声明折线和线性密度的服务积分，不是连续空间全局优化或连续Lloyd更新。

重观测时，将三种名义贪心布局投影到当前观察曲线，作为所有选择器共享的候选。
这三个锚点固定来自名义观测，不随其他实验方法的后续结果滚动更新。
每个扰动都从同一名义观测独立构造，大小间共享方向；不是将扰动累积成一条时间轨迹。
所有候选仍须通过完整自由空间包含和全部成对欧氏间距检查。

## 保留规则及可证明范围

设本群共享有限候选池为C，连续观察欧氏未覆盖比例为U，最优值为u*=min U(c)。
若名义欧氏布局投影后的候选a仍通过全部安全准入，且U(a)≤u*+δ，则保留a；
否则选当前最优候选。主容差δ=.002，即0.2个百分点；.005作预先指定的敏感性分析。
容差是显式的观测服务代价预算，不修改安全距离、成功阈值或数值接受容差。

对每群都有U_k(retain)≤U_k(greedy)+δ，因此：

    max_k U_k(retain) ≤ max_k U_k(greedy)+δ
    sum_k w_k U_k(retain) ≤ sum_k w_k U_k(greedy)+δ,  w_k≥0, sum w_k=1

这是当前观测、本群指派服务、同一个有限池内的界。
没有建立真实/估计服务点的需求质量对应，因此它不直接约束公共真实参考服务。
所有机器人共同服务时可能存在跨群耦合，该界不能据此解释成全局欧氏覆盖最优性。

该规则也不保证全局目标连续性：投影、多边形拓扑、准入状态和最优候选都可能切换。
本轮固定资源数量，不能用其结果声称已解决整数资源重分配的跳变。
目标匹配RMS是规划敏感性指标；真实行驶距离通过另存的部署轨迹测量。

## 实验与独立重复

协议`configs/step1/static_phase_retention_v1.yaml`：K=2/5，凹形/椭圆，每条件20 seeds
（2200–2219，namespace=2026102706）。80个独立(K,shape,seed)物理块，
两种基线误差、四档附加扰动、五种选择器，共3,200条规划结果。
基线误差上界.08m，附加误差0/.001/.01/.03m，声明规划上界始终.12m。
`common_bias`表示名义误差为共同偏差；其后叠加的微扰是逐人有界方向。

主分析为1mm时.002保留策略减连续欧氏贪心的目标匹配RMS。
先在每个物理块内平均两种基线误差，再对四个K/shape层等权；bootstrap重采样完整种子块。
缺失块保留，按照房间对角线50m给出保守差值范围，不以成功子集替代完整账本。
所有新方法结论属于开发证据，不替换原v2确认的主指标。

独立圆盘误差的80个名义场景另执行共同欧氏部署；1mm重观测后两种主比较策略
从同一份名义机器人终态出发，共160次实际重部署。
名义失败不补抽；执行失败、未执行和程序错误保留；程序/安全违反触发停止。
每阶段速度、1800s截止、到达保持及所有安全阈值沿用原模型。
真值评价核查整个常速度区间的机—人、机—机、机—墙距离，独立计算实际连续服务。
