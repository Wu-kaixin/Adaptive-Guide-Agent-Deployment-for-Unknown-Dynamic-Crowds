# Step 1 条件服务界：适用范围与推导

本文件对应2026-10-28的新子问题，不替换原世界坐标公共参考。原独立人员误差下的真实服务界仍未解决。

参考以第一名稳定人员为锚点，将相对位置量化到1e-8m网格，使用原几何及需求构造。
仅在人员误差为同一个平移向量、范数不超过ε、半径/需求准确、身份稳定，且相对坐标计算误差满足声明上界时使用。
观测相对位置到量化分界面的距离须大于4倍声明计算误差，否则UNCERTIFIED。
这些条件使量化后的相对人员输入一致，从而构造同一局部曲线及同一需求测度；一般独立误差不具有此对应。
该构造不使用人员真值作控制器输入，真值只用于独立审计。

对每群完整机器人集合Q，在观测锚定参考上以服务半径r+ε计算缺口下界L，以r−ε计算缺口上界H（r<ε时上界1）。
于是理想几何模型中L≤U_true≤H。保留减贪心的每群真实缺口损失至多H_ret−L_greedy。

为避免区间过宽，另给配对界。设h为贪心机器人集到保留机器人集的单向Hausdorff距离。
任何由贪心服务、却未被保留服务的点，必在某个贪心机器人半径(r−h,r]的内环带中。
沿连续的候选曲线段簇，若所有允许平移下径向导数同号且绝对值至少m，环带内弧长至多h/m；
乘以该段簇最大线性需求密度，并以段簇总质量截断，得到质量上界。不能证明同号的段簇使用完整质量。
对所有机器人求和再截断到1，得到B。使用min(B,H_ret−L_greedy)作每群损失上界。
所有群的上界均不超过预先指定Δ才保留，否则使用同一贪心目标。

若双方机器人终态到其目标的距离均不超过τ，则在配对界中用h+2τ及平移邻域ε+τ，在单布局界中用ε+τ。
独立实际轨迹审计必须检查该终态条件、群身份、真实缺口损失和所有安全区间。未安全完成不能冒充已交付保证。

实现使用float64及显式数值垫量，属于声明误差条件下的数学模型和数值审计，不是经过形式验证的机器区间证书。
新旧公共参考差异单独报告，开发样本中的小差异不能推广为两种参考的通用等价证明。
旧3200条固定动作中640对保留/贪心均不被这个新模型认证；seed2210反例明确回退，不重新优化旧动作。

接口保留时间戳、误差模型、证书状态与回退原因的扩展位置，但本轮不含动态人群、相对运动稳定性或通信延迟证明。
