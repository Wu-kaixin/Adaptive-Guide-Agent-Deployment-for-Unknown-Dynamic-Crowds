# 静态服务评价、误差关系与扰动稳定性

本轮研究仍限于静态人群、全局有界误差观测、无限通信、固定预算和无行为响应。
冻结 v2 采用保存的源码快照执行；新机制实验、服务审计和扰动实验属于独立开发证据。

## 连续服务计算的模型

`udc.multigroup.service` 评价闭合折线及其顶点上声明的非负需求密度。
两个顶点之间的需求密度按弧长线性插值，这与既有 `quadrature_mass` 所积分的模型一致。

给定线段 x(t)=a+t(b-a)，t∈[0,1]，机器人中心 q、服务半径 r 的服务区间由
||a+t(b-a)-q||²≤r² 的二次不等式给出。对所有机器人得到的区间取并集，再在并集上
解析积分该段线性密度。周期弧距服务则直接合并周期区间并积分分段线性密度。
因此结果消除了固定采样网格对硬服务阈值的积分误差，但仍是普通 float64 计算；
它不是区间算术证书、不是原始圆弧的精确几何、也不是人的行为影响模型。

`full_curve_covered` 检查整段区间并集，而不以积分后的缺口比例恰好为零替代。
曲线上密度为零的区间即使无人服务，也不会影响需求缺口，但仍影响整曲线覆盖。

## 人员误差不能直接代替边界服务误差

定义归一化的估计/真实服务测度，机器人集合固定。
如果存在保持需求质量的点对应，且所有对应点欧氏位移≤δ，那么最近机器人距离的
1-Lipschitz 性质给出：

    U_hat(r+δ) ≤ U_true(r) ≤ U_hat(r-δ),  r≥δ

若 r<δ，右侧采用平凡上界1。r-δ=0 处须沿用同一硬阈值定义。
证明：估计点到机器人距离≤r-δ时，其对应真实点必被服务；真实点被服务时，其对应
估计点到机器人距离≤r+δ；对质量保持对应积分即可。

这是条件性数学引理，不是声称现有估计器已满足条件。人员误差≤epsilon、占据集外包围或
单独的集合 Hausdorff 距离都没有自动给出弧长/需求质量对应。
固定机器人时，服务阈值附近的需求质量还控制硬覆盖比例对误差的敏感程度。
下一项理论工作是识别哪些非凸几何与需求条件可构造该对应，或给出可计算的上下界。

## 分群稳定的充分条件

相对于一个参考观测分区，若每群在阈值 h-2η 下仍连通，且跨群任意观测中心距离>h+2η，
那么每个中心任意移动≤η后，在阈值h得到的连通分区不变。
证明来自任意点对距离变化≤2η：群内保留一棵连通生成树，群间不会新增连接。
实现 `partition_stability_certificate` 只使用参考观测及其分区。
证书不成立意味着该充分条件不能判断，不意味着一定切换或物理不可行。
实验另保存一个1 cm扰动使2群合成1群的显式阈值反例。

分群稳定不保证整数分配、有限相位目标或路径稳定。实验单列资源数量L1变化、
目标集合Hausdorff距离、相同目标数量时的最小匹配RMS，以及公共真实参考服务变化。
所有新增微扰保持实际人员位置误差≤声明的.12 m；人群真值始终固定。
`common_bias`表示基线误差为共同偏差；随后与另一模型一样叠加逐人独立方向的有界微扰，
并非声称叠加后的全部误差仍是纯共同偏差。

## 公平性、总体服务与统计口径

新增 `total_allocation` 在与 minimax 完全相同的观察候选目录上最小化需求加权缺口，
再优化归一化距离成本；相同质量时少用机器人并确定性破同分。
它不是公共真实参考服务的全局最优。常规加性DP不作为首创贡献。

机制实验固定K，独立改变大小模式、每人需求模式和预算。删除生成器原有的群体ID
需求倍率，使每人需求相等的条件确实相等；人数差异仍会改变群需求总量，必须保留并解释。
20 seeds以(K,seed)为配对块，大小/需求/预算/方法不能当作新增独立样本。
所有机制与扰动实验为规划阶段，不对实际部署完成率作结论。

v1单独改变每个群的需求整体倍率。归一化缺口满足 U(cρ)=U(ρ)，所以该倍率不会改变
单群服务曲线形状或最差群体的首要准则，只影响总需求权重和后续破同分。
v2另行改变群内热点形状，并保持每群平均每人需求为1，区分总量与空间分布的作用。
v1零差异和v2结果都保留，均为开发机制分析，不按结果方向筛选条件。

冻结 v2 主效应继续是双方有计划时的计划服务差异。补充分析按完整预定配对数
报告部分识别范围：每个缺失未覆盖比例限制在[0,1]，对差值的上下界求分层均值。
如果一方已知，使用该已知值收紧界；双缺失差值界为[-1,1]。
这些是缺失值下的识别界，不是置信区间，也没有给程序异常或科学失败虚构服务值。
实际安全完成服务另给范围，未安全完成的任务按服务未确定处理，不从完整账本移除。
