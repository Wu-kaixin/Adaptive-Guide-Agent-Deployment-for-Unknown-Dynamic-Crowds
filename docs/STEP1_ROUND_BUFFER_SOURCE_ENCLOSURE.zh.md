# 默认圆角buffer的条件坐标来源组合

`multigroup/round_buffer_source_enclosure.py`将已声明的有限偏置、圆弧、段求交和精度契约，
接到默认圆角buffer的坐标生成分支。它输出条件外包，始终保留`all_inputs_defined=false`和`service_certificate=false`。
本轮没有恢复运行门控，也没有完成未知原参考、有符号质量或Step1整体稳定性闭环。

## 输入与来源义务

输入是包含全部输入环顶点的全局轴框B，以及实际传入的buffer距离。
适用范围为默认FLOATING工厂、圆join／cap、非single-sided路径，以及已审查GEOS 3.14.1源码。
有限坐标生成运算、正计算范数、正确舍入sqrt、单位范围有限三角分量和通常XY复制／存储语义是明确条件。
不覆盖mitre／bevel模式、非零noder平移、任意fast-math重关联或尚未审查的精度路径。
正负多边形buffer的源偏置使用距离绝对值，侧别变化不影响这个对称外包。

本轮依据[OffsetSegmentGenerator.cpp](https://raw.githubusercontent.com/libgeos/geos/3.14.1/src/operation/buffer/OffsetSegmentGenerator.cpp)、
[OffsetCurveBuilder.cpp](https://raw.githubusercontent.com/libgeos/geos/3.14.1/src/operation/buffer/OffsetCurveBuilder.cpp)及
[BufferInputLineSimplifier.cpp](https://raw.githubusercontent.com/libgeos/geos/3.14.1/src/operation/buffer/BufferInputLineSimplifier.cpp)
逐项复核来源；结合此前结点与图输出的源码审查，封存39个上游文件及原版权／COPYING。
这是源码层人工条件推导，不是全部依赖、编译器或二进制的形式验证。

| 坐标来源 | 条件外包 |
|---|---|
| 简化、重复点删除、输入顶点选择 | 仅复制／删除输入，仍在B内 |
| 段偏置端点 | 由有限法向cap给出N，参见[有限偏置分支](STEP1_FINITE_OFFSET_ENCLOSURE.zh.md) |
| 圆弧和圆cap | 中心在B，使用[圆弧源界](STEP1_CIRCLE_SOURCE_ENCLOSURE.zh.md)A |

## 辅助闭合段与舍入

源码使用k=1，或在默认圆join和足够quad_segs时使用k=80。
辅助点每坐标表达式为(k·o+c)/(k+1)，o是偏置端点，c是原顶点。
乘法、加法、除法的舍入意味着该表达式不必留在理想输入凸包：
o=c=0.1时，分离运算输出比0.1少一个ULP；0.7例会多一个ULP。
这些是确定性算术夹具，不是本批实际GEOS内部辅助点已观测越界的证据。

`closing_auxiliary_box`利用k>0和各算术映射的单调性，在两个输入坐标区间的可表示极值上求：

- 分离分子：RN(RN(RN(k·o)+c)/(k+1))。
- 融合分子：RN(RN(k·o+c)/(k+1))。

对两种关联取外包，显式覆盖允许的分子融合。k及k+1均是可精确表示的整数。
没有使用经验pad，没有假定任意编译优化都等价于这些表达式。

原始源框R取B、N、A及两种k辅助框的轴向包络。
辅助点不会回流为下一段的原始输入顶点，因而这里不需要无穷次辅助点闭包。
在声明的原精度／固定回退路径上，再接[统一精度两阶段界](STEP1_UNIVERSAL_PRECISION.zh.md)，得到完整输出的条件粗框。
它没有据此证明所有允许输入均满足有限范数条件、没有异常，或整个原参考已经可用。
