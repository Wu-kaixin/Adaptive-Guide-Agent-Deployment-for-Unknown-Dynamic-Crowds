# 局部偏置的条件有理区间契约

后续[有限运算分支界](STEP1_FINITE_OFFSET_ENCLOSURE.zh.md)补充了不依赖输入族最短边长的统一法向cap。
它不改变本文整族准入／拒绝；对可能零范数的33个旧偏置条件，依旧不能声称全部输入已定义。

## 当前能力与目标中的位置

`multigroup/offset_interval.py`实现有限端点区间下的局部偏置表达式外包，
并提供“精确直线相交后仅舍入最终坐标”的另一个条件原型。
它不改变原参考、默认控制执行或验收阈值；默认原参考支持域门控仍不可认证／回退。
这一步用于补实现误差传播的基础件，**没有完成F4一般误差证书，更没有完成全部Step1目标**。

偏置表达式与固定GEOS3.14.1的[computeOffsetSegment](https://raw.githubusercontent.com/libgeos/geos/3.14.1/src/operation/buffer/OffsetSegmentGenerator.cpp)对应。
这里是源码表达式的独立二进制重现，不是GEOS内部插桩。
交点原型不模拟GEOS的double-double求交、简化、顶点合并或布尔结点算法。
不能将给定线段端点的坐标不确定区间，未经证明直接等同于人员位置误差ε。

## 运算模型与外包

假设有限binary64基本运算按最近值舍入，sqrt正确舍入，表达式结合顺序与源码一致。
不覆盖任意fast-math重结合、非最近舍入模式或溢出路径；这些条件不能建立时拒绝。
令u=2^−53，η=2^−1075，使用包含次正规数的绝对界

    |RN(z)−z| ≤ u|z|+η。

输入端点区间为精确有理数。加、减、乘、除先进行精确区间运算，
每次需要模拟binary64舍入时向外加入上述误差界。
sqrt用整数平方根构造有理上下界，再加入舍入界；不用float sqrt判断包含。
中间区间投影到分母2^160的格点时，下界取floor、上界取ceil，始终向外。
η在投影前显式计入，不会因为浮点下溢而被当成0。

对端点A、B，按源码结合顺序外包

    dx=RN(B_x−A_x)，dy=RN(B_y−A_y)，
    q=RN(RN(dx²)+RN(dy²))，L=RN(sqrt(q))，
    ux=RN(RN(side*d*dx)/L)，uy=RN(RN(side*d*dy)/L)，
    P'_x=RN(P_x−uy)，P'_y=RN(P_y+ux)。

同一变量平方使用非负平方范围。q的通用舍入外包可能有负尾，
用“两个非负binary64平方之和不能为负”的精确符号不变量截去负尾；不是容差放行。
若L区间含0，返回UNCERTIFIED，不改输入区间、不选择某个方便的方向、不重抽样。
分母区间可能含0、sqrt条件不成立或溢出契约不能建立时同样拒绝。

初次定向检查暴露的是负尾导致拒绝原因错分；在冻结v1科研批次前按上述符号不变量修正。
修正没有把可能零长度的输入判成有定义，仍返回`segment_norm_interval_contains_zero`。

## 法向分量的依赖约束

独立区间计算会丢失“分子dx和分母L来自同一段”的依赖，可能把半径0.4m的偏置放大到数米。
v2通过推导的约束收紧，未采用测得的最大误差或经验pad。

对任一实际分量x∈{dx,dy}，非负平方及舍入模型给出

    q ≥ (1−u)²x²−(2−u)η。

设已有q区间下界q_min>0，sqrt(q_min)的有理下界为l0>0，
α=1−u−η/l0>0，L区间下界为L_min>0，则

    |x/L| ≤ K = sqrt(1+(2−u)η/q_min) / ((1−u)α)。

分子sqrt使用有理上界。再计入d*x及除法的舍入后，每个偏置分量有绝对界

    |u_component| ≤ (1+u)² d_max K + (1+u)η/L_min + η。

将原区间与这个经过证明的对称界求交；若辅助前提不能成立，则不应用该收紧。
辅助界没有改变半径d，也没有改变服务预算或安全阈值。
它只修复一部分区间依赖过宽，不给出原参考弧长或需求质量界。

## 精确相交原型的独立条件

四个线段端点框先以有理区间进行行列式及参数计算。
可能平行时行列式区间含0，拒绝；否则外包所有允许端点的精确直线交点，最后外包一次坐标舍入。
它不宣称GEOS交点总是正确舍入的精确交点。
一组已保存闭运算反例恰与这个原型吻合，是局部重建证据，不能向整个内核推广。
本原型也不自动保证交点位于两条有限线段之内，不能将其当作完整线段相交判定。

## 冻结开发与复判

两个版本都使用同一个旧`K2_concave_s2200`正buffer的33条边：32个等索引选择与2条已暴露反例边的并集。
每条边给定四档独立端点坐标误差：0、1e−12、0.001、0.12m；另对反例相邻两边给出四档相交条件。
共132偏置条件＋4相交条件＝136条件，不是136个独立物理输入。
这些端点框是新局部运算条件，不是对原0.12m人员观测协议的重新标注。

每个偏置条件保存中心＋16个向内舍入的端点框角点重现，相交条件保存中心＋64角点。
两版本各2504条表达式重现，不能将它们当作独立随机样本。

每版本101个条件有有限外包、35拒绝，无重现输出逃出已给外包；v2中25/101外包严格收紧，其余没有变宽。
所有拒绝条件及原因保持，未通过收窄输入集合提高认证数量。
33个大端点框拒绝条件均保存了同一允许点作为两个端点的零长度见证，精确检查其在两个框内并重现偏置无定义。
剩余两个拒绝不能由这个见证计作普适不可能性：它们是相交／传播区间未能排除退化。

两版本独立工件复判不调用区间构造器，直接重现全部2504条表达式，
精确核验每版本38696次观察到的基本运算／sqrt舍入契约、520次最终交点坐标舍入及所有保存框包含。
所有输入坐标、receipt及结果hash核验，33个零长度见证重新核验，差异0。
有限观察运算检查只是条件运算模型的实现证据，不是对任意编译环境的正式证明。

工件位于`runs/step1_foundation_20261029/local_offset_interval_development_v{1,2}`及各自`_audit`。
协议位于`configs/step1/local_offset_interval_development_v{1,2}.yaml`，旧反例及哈希不改写。

## 尚待闭合

这一步有非零端点不确定性能力，但尚未把所有允许人员世界映射到偏置输入框，
也未覆盖输入简化、拓扑变化、实际GEOS求交与结点处理。
必须补齐这些契约及原参考的有符号质量界，才能讨论恢复一般误差服务门控和新的独立确认。
不能用101个局部有限外包充当101次部署成功或原低资源证书认证。

后续已实现实际GEOS无量化段求交的结构返回点外包，直接覆盖正常包围盒检查及端点回退，269次C API调用及再次复判一致。
它无需假定DD为精确交点的正确舍入，但不提供交点定位误差或相交存在保证。
原BufferOp还有固定精度／snap-rounding回退，整个原参考仍未闭合，见[原生接口契约](STEP1_NATIVE_INTERSECTOR.zh.md)。
