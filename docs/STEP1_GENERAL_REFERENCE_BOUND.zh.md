# 一般独立误差下原参考的支持域界

本模块使用原世界坐标、原人员生成的外包络、原膨胀和重采样参考，不改变需求权重或评价对象。
误差可以独立、相关或对抗地取值，只要求每名人员的欧氏位置误差不超过ε、人员身份/半径/需求准确。
保证以原参考成功定义为条件；参考构造失败仍是科学失败，不能把没有定义的服务当作通过。
实现是float64几何审计，以下是几何模型推导，不是经过形式验证的GEOS或区间算术证明。

## 支持域

原构造使用64边外接人员多边形，令c₆₄=cos(π/64)、人员半径rᵢ、构造裕量m、闭运算半径a、外偏移b、最大重采样弧步长s。
观测为zᵢ，真实人员pᵢ属于B(zᵢ,ε)。真实构造多边形被B(zᵢ,(rᵢ+m)/c₆₄+ε+原构造垫量)包含。

最保守外界可直接用这些观测包络的凸包再外扩a+b。
对原16段/象限圆角缓冲，可用弓高界：正缓冲位移不超过a，负缓冲内部净距至少a c₆₄，
因此闭运算整体被原凸包外扩a(1−c₆₄)包含。填孔仍处于该凸包外界。
再外扩b并使用外接圆角多边形，即得外界O。保留最保守a界和弓高界两个实现选项以便审计。

每个真实构造集总包含B(zᵢ,rᵢ+m−ε)（该半径为正时）。原外偏移包含该圆盘再膨胀b c₆₄。
重采样弧间隔不超过s，每条采样弦到原缓冲边界不超过s/2，因而所有参考点避开
B(zᵢ,rᵢ+m−ε+b c₆₄−s/2)的严格内部。
从O扣除这些内排除圆盘的内接近似得到支持域S。内外构造分别向保守方向留1e−9m构造垫量，不放宽物理安全距离。

这个构造同时考虑膨胀、闭运算、填孔、偏移和折线重采样，未假设“人员误差等于曲线误差”。

## 群身份

首先使用原观测图的减小连接半径充分证书。若它过于保守，还可使用以下有条件推论：
观测分量间距离大于link+2ε时真群不能合并。
若一个观测连通分量在真值中分裂，必有一条观测图边跨越两个真群，真实人员距不超过link+2ε。
但各真群的采样部署内部至少包含以该人员为中心、半径rᵢ+m+b c₆₄−s/2的圆盘。
若link+2ε小于两内核半径之和，这两个部署内部重叠；原参考的群间环距/占据分离条件会拒绝该真值。
因此在原参考成功定义的状态中分裂也被排除。不存在参考时仍保留失败分母。

主运行默认只接纳直接由观测减小连接半径得到的充分证书；上述依赖原参考结构的条件推论单独记录，
`support_conditional_identity`默认为False，不凭真实参考的事后检查来放宽运行门控。

## 服务区间与损失门控

对完整机器人集合Q及允许的终态误差τ，构造保证服务内集C⁻(Q)（半径r−τ的内接圆盘并）
和可能服务外集C⁺(Q)（半径r+τ的外接圆盘并）。
若S被C⁻覆盖，则原参考任意非负需求测度的缺口U=0；若S与C⁺不相交，则U=1；否则区间[0,1]。
这些区间可能很宽，必须报告适用率，不能只报告没有反例。

更直接地，若

    S ∩ C⁺(Q_greedy) \ C⁻(Q_retained) = ∅

则任何可能被贪心服务的原参考点都必被保留服务，从而每个真实群的U_retained−U_greedy≤0。
这与真实需求密度、边界参数化以及独立误差分布无关；也支持群数量分配不同但总预算相同的完整布局。
只有所有群的支持域都通过才接受，否则UNCERTIFIED并回退同一贪心。

它是零额外服务损失的充分条件，不是对所有资源档位都能认证的必要条件。
资源不足时往往无法认证；必须保留回退及其运动/服务代价，不能声称已经得到普适的稳定更新收益。
后续实验对旧640对动作及seed2210固定反例、独立新输入、50次连续重观测分别验证，不能把这些阶段混作新独立样本。
