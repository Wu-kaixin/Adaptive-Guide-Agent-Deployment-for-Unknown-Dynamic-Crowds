# 精确观测条件下的原参考有符号质量证书原型

本模块补充原始精确观测Step1的一个定量基础件，**不解决非零观测误差下的未知原曲线问题**。
默认稳定更新门控没有改用本模块，旧640对及50／200步一般误差结果不重标、不重跑。

## 输入条件和比较对象

`multigroup/exact_reference_certificate.py`的`exact_observation_certificate`只接受声明位置误差严格为0的观测。
半径、需求精确的旧契约不变。原世界参考因此可由这一帧观测调用原构造和原Gaussian结点映射得到，
不是把另一个锚定参考代替原参考，也不把之前的精确参考沿用到以后有误差的观测。
任何非零误差，包括1e−15m，都在参考构造前返回UNCERTIFIED；不读取评价真值。

给定贪心计划布局Q_g、保留计划布局Q_r、服务半径R、保留实际终态逐台跟踪界τ<R。
若实际Guide与Q_r匹配误差均≤τ，其R服务圆盘并集包含Q_r上半径R−τ的圆盘并集。
因此原逐群损失满足

    U_actual_retained − U_planned_greedy
        ≤ U(Q_r, R−τ) − U(Q_g, R)
        = ∫ρ(s)[I_g(s)−I_r,shrunk(s)]ds / ∫ρ(s)ds。

比较对象仍是同一原参考上的贪心计划布局，不偷换成更弱的另一次实际执行。
证书只保证服务损失；布局、路径、速度、到达保持、实际跟踪界和物理安全仍须原流程独立检查。

## 保守计算

原参考的保存浮点坐标及结点需求视为精确二进制有理输入，需求沿每条完整弦段线性插值。
不是将沿弦连续Gaussian场代替原结点线性模型。

1. 对每个二进制细分弦段，用有理数计算到各圆心的端点最大距离和整段解析最小距离。
   端点均在某一圆盘内即可保证整段覆盖；到所有圆盘的整段最小距离均≥R时，几乎处处不覆盖。
   相切点弧测度为0；非零直线不能沿圆周重合，不把边界点的零质量当作正服务。
2. 独立得到两个覆盖指示函数的0／1上下界，再形成I_g−I_r的−1／0／1有符号界。
   已证明的新增服务可抵消丢失服务，不只积分单向正损失。
3. 每个细分区间的线性需求系数用Fraction精确积分。欧氏边长平方为有理数，
   以整数isqrt产生96位二进制平方根上下包络；正负项按符号选取保守边长界。
4. 全质量分母取严格正下界；有符号分子按其符号组合分母上下界。
   只在精确有理正损失上界≤原0.002的二进制表示时接纳。输出float上界朝上舍入，不用它决定通过。
5. 自适应细分优先处理质量不确定度最大的区间。达到4096叶区间／深度18仍未证明时拒绝，
   不能把有限预算拒绝解释为真实损失超预算或物理不可行。
   收缩圆盘比较超预算也不直接证明真实实际终态超预算，因为收缩本身是保守下界。

有理测试与积分包络针对已给定有限折线／结点需求；没有因此形式验证GEOS构造、Gaussian浮点实现、
旧float64积分器或整个机器人软件。旧评价器仍另行审计，不放宽其原接受阈值。

## 开发证据与局限

`exact_certificate_development_v1`使用旧动作、旧人员生成一个**另行声明的完美传感输入条件**，
不把旧有噪声观测的声明误差从0.12改成0，也不将评价真值用于旧控制器放行。
8对来自原清单前两个序列的四种扰动动作，另加两个保留的seed2210超预算反例，共10对。
原布局不优化，没有新运动、没有新独立物理样本；这是证书诊断，不是闭环确认。

精确条件接纳8/10，其中7对布局相同、1对非相同；非相同布局共3对，另外2对超预算反例均拒绝。
0.12m误差输入0/10接纳；旧640对一般误差认证仍0，F4整体未闭合。

非相同接纳例K2_concave_s2200_bounded_disk、30mm旧动作：
float64收缩比较最大逐群损失0.0011310678173982458，保守有理上界报告0.0019464528085839032。
两seed2210例的float64收缩损失分别0.002159772222494194、0.011346670537230596，均不放行。
所有保存的float64收缩比较均不高于对应有理上界，无数值反驳，也没有容差兜底。

有理原型尚未接入默认稳定更新。精确静态观测本身没有持续噪声变化，不能用这一条件代替一般有界误差收益验证。
下一步仍须为未知原曲线建立从观测可证的质量／几何包络，或明确排除不可区分坏世界的附加条件。
不能简单地把本证书作用于有误差观测构造的曲线，并声称得到了原世界保证。
