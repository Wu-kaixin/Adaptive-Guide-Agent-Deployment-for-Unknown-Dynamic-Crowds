# 分阶段实验协议

## 当前整合验收

本轮是框架迁移与 smoke，不能视作论文盲验证或全部 Step 1 闭合。
检查：既有测试、新增冻结源与核密度回归、默认场景、50 人案例、保存轨迹复判、批量失败记账。
Equal Arc 与 Average CVT 的迁移结果与来源仓库逐数组比较；Mass CVT 因核密度修复单独评价。

## 后续主要实验

1. 固定部署、导航与安全层，比较凸包和后续 alpha／radial 边界。
2. 固定边界，比较 Equal Arc、Average CVT、Mass CVT、DistMesh-inspired。
3. 固定目标，比较路径与协调方式。
4. 两群静态过渡实验后，再逐项增加移动、扩散、分裂和合并。
5. 群体数量扩展至 1、2、3、5，规模扩展至小／中／大，资源扩展至充足／适中／严重不足。
6. 完整方法稳定后做动态分配、风险权重、重分配消融，最后测试噪声、速度和交互参数。

方法比较必须共享保存的人员快照和 Guide 初态，相同 seed 字面值本身不能保证公平配对。
固定 N 比较与自适应资源比较分别报告，避免更多 Guide 被误解释为算法更优。
均匀权重 CVT 可能退化为等弧长；不把名称不同自动视为独立竞争基线。
多人群时先固定总人数比较群体数量，再单独增加总规模。

## Seed 与版本纪律

`experiments/acceptance_manifest.yaml` 保留全部四方法与两资源协议。
开发 seeds 为 0–29；未来 validation seeds 5000–5029 暂不运行。
当前的 smoke 只使用每个随机场景一个开发 seed；确定性失败夹具固定 seed=0。
修改实现或成功标准后，旧结果保留，采用新的输出目录与冻结提交重新运行。
不能把来源仓库的 7216/7216 completed、5342 SUCCESS 或 153/160 回归率直接当作整合分支结果。

主要配置计划使用约 20–30 独立 seed；结论不明确时按不确定性增加样本。
确定性 50 人网格重复运行用于工程复现，不构成独立统计样本。

## 报告要求

成功率、终止分布、程序错误、覆盖缺口、最小净安全距离、活跃 Guide 数和运行时间分别报告。
`udc-summarize` 给出成功率 Wilson 95% 区间和成功任务时间均值／中位数。
批量程序错误通过保存的任务标签计入对应场景／方法／协议组；没有任务标签的旧错误保留为独立错误组。整体任务数包含全部错误。
配对差值与 bootstrap 区间将在正式主要比较中补充，目前 smoke 不用于显著性结论。
失败和资源不足不能从分母删除。时间统计注明成功任务子集，并同时展示失败率。
