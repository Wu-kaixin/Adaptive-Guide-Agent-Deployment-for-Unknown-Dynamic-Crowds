# 不依赖最短边长的有限运算分支偏置界

`multigroup/finite_offset_enclosure.py`对声明源码表达式的有限运算分支给出统一坐标外包，
不需要人员／几何输入框的最短边长下界。
它与旧的整族区间运算准入不同：旧33项可能零范数拒绝全部保留，默认门控未改，F4及完整闭环未完成。

## 源码表达式与条件

固定GEOS 3.14.1的[computeOffsetSegment](https://raw.githubusercontent.com/libgeos/geos/3.14.1/src/operation/buffer/OffsetSegmentGenerator.cpp)
计算binary64差分dx、dy，平方和q，L=sqrt(q)，再计算d·dx/L、d·dy/L及端点偏置。
本契约要求这些基本运算有限、q>0，采用最近舍入和正确舍入sqrt；距离非负。
本轮用Python binary64重现该表达式，没有新增原生GEOS调用或C++内部插桩。
因此不能把重现结果冒称编译二进制路径验证。

## 推导

令u=2^-53、η=2^-1075。任意非零binary64计算平方和满足q≥2^-1074。
由于非负加法和单调舍入，q至少等于每个单独舍入的平方s=RN(x²)，x为dx或dy。
若一个平方与加法融合，非负项的单调性仍给出该支配关系；本批重现仅执行分离运算关联。
由s≥(1−u)x²−η，得到

x²≤(q+η)/(1−u)，且η/q≤1/2。

sqrt(q)≥2^-537处于正规数域，故L≥(1−u)sqrt(q)，且由单调性L≥2^-537。
于是

|x/L|≤sqrt((3/2)/(1−u))/(1−u)。

对乘积RN(d·x)和商再传播舍入，令D为距离上界，取sqrt((3/2)/(1−u))的精确有理向外上界R：

B(D)=(1+u)²·D·R/(1−u)+(1+u)η/(2^-537)+η。

两法向分量绝对值均≤B(D)，无需观测端点框的长度下界；D=0可直接用0。
最后每个端点坐标的最小／最大可表示输入分别与±B(D)相加再RN，给出输出坐标框。
平方根上界用整数isqrt及2^-160向外格点计算，不添加经验pad或放宽验收容差。

这里不以“几何端点不同”替代“计算q>0”：很短的非零差分平方可能下溢为0。
也不处理运算中出现无穷的路径；即使某些后续运算碰巧得到有限坐标，也未因此满足本契约。
返回对象始终显式`all_inputs_defined=false`、`service_certificate=false`。
它只包围满足条件的分支，不排除、不认证也不静默丢弃同一输入族里的未定义成员。

## 理想单位法向界的算术反例

受控输入a=(0,0)、b=(x,0)，其中x的hex为`0x1.3988e1409212dp-537`，距离0.4m。
精确x²约为最小正binary64的1.5倍，但舍入计算平方和是
`0x0.0000000000001p-1022`，长度恰为`0x1.0000000000000p-537`。
法向分量绝对值约0.4898979485566355m，为距离的1.2247448713915887倍；
新有理界约0.4898979485566358m，覆盖该值。
输入、各步hex、精确平方／计算范数的有理比值和最终坐标全部保存。

这是平方在次正规区向下舍入造成的具体机制，不是预设浮点噪声后改容差。
它反驳理想的“任意有限计算法向分量≤d”直接实现转移，不证明旧人群输入族曾出现此极短边。
该夹具是推导后选定的确定性算术反例，不是独立随机确认样本或旧部署安全失败。
