## 计算不变量

`multigroup/accelerated_execution.py`保留原有限图的全部节点与潜在边。
原节点顺序、线段方向、高/低节点索引顺序、几何谓词、边权计算和严格松弛均保留。
先按原规则过滤节点，再为同一个自由空间对象建立Shapely索引；WKB不变。
端点编号仍为0和1；候选邻居按原索引递增。搜索仍使用相同的heap和破同分规则。

边权非负。对当前出队距离d和候选边权w，如果d+w不能严格改善当前距离，
原松弛也不会改变状态，因此可以不执行该边昂贵的可见性谓词。
其余边仍用原整段谓词判断，没有以启发式删边或改变自由空间。
目标出队后，后续非负路径不可能严格改善目标距离；相同严格破同分下目标前驱保持不变。
因此可以按需计算边并在目标确定后结束，不必先建立完整邻接矩阵或遍历无关剩余队列。

这是一项对原离散计算的等价性论证，条件包括几何库索引与非索引谓词语义一致、
同版本数值计算及节点/边顺序保持。不是任意浮点几何的机器证明或动态安全证明。
没有更改0.75m间距、障碍分辨率、目标、移动顺序、指派、科学截止或真实服务指标。
